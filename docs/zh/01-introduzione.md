# 简介

🌐 [Italiano](../01-introduzione.md) · [English](../en/01-introduzione.md) · **中文**

> ⚠️ 本页为机器翻译草稿，正式发布前需母语者校对。

这个工具源自一个 shell 脚本，我原本用它来记 subfinder 的命令：标志怎么选、按什么顺序做、哪些该做哪些不该做。它相当于一份可执行的笔记。脚本能用，但有个缺陷：文件开头的变量只要写错一个，就会对一个毫不相干的目标发起运行。

`subfinder-cli` 消除了这个缺陷。作用域变成一个文件，里面写明名称、授权人签名和有效期。目标在命令行中指定，并在系统去 `PATH` 中查找 subfinder 之前就先与该文件比对。

## 三个设计决策

**默认行为就是 dry-run。** 不加 `--esegui` 时，程序只打印命令并记录下来。误启动比什么都没启动更难发生。

**拿不准就拒绝。** 格式异常的目标、host 部分带凭据的 URL、解析到被排除地址的主机名：一律拒绝。误拒的代价是改一行作用域；误放行的代价是一起事故。

**零依赖。** 只用 Python 标准库。一个要为自己所运行的内容负责的工具，不应该再拖上五十个需要你去信任的包。

## 仓库内容

```
subfinder-cli/
├── src/subfindercli/
│   ├── scope.py      加载作用域，判断目标是否允许
│   ├── spec.py       subfinder 的配置、被禁标志和结果格式
│   ├── profili.py    配置结构和标志过滤
│   ├── runner.py     构建并运行命令（从不经过 shell）
│   ├── audit.py      哈希链审计日志
│   ├── risultati.py  结果的读取、汇总和比较
│   └── cli.py        参数、提示信息、退出码
├── tests/            unittest，无需网络，无需安装 subfinder
├── docs/             本文档
├── examples/         作用域示例
├── lab/              故意留有漏洞的靶机（Docker）
└── scripts/          最初的 shell 速查脚本
```

## 适合谁

受委托做安全测试、希望清楚记录运行了什么、何时运行、依据哪份授权的人。正在学习、希望从第一天起就养成好习惯的人：先定作用域，再执行命令。带团队、不希望任何人把从聊天里复制来的目标直接贴进命令的人。

## 不适合谁

想要隐蔽行动或越界操作的人。用于这些目的的标志都已被禁止。
